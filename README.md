## 🏗️ Featured Project: Hybrid RAG Architecture

Built a production-grade multilingual document intelligence system for a GCC fintech marketplace. Investment analysts went from spending 2-3 days manually reviewing pitch decks to getting grounded answers in under 2 seconds.

**Stack:** Gemini Pro + Tesseract + PyMuPDF + Arabic Reshaper + BiDi + paraphrase-multilingual-MiniLM-L12-v2 + Qdrant + BM25 + Reciprocal Rank Fusion + GPT-4o + FastAPI + AWS App Runner + Vite + AWS Amplify + MongoDB + Docker

**Key metrics:**
- MRR 0.12 to 1.0 on Arabic retrieval
- 42ms retrieval latency
- Under 1.2s end-to-end response
- 95% OCR accuracy (English) / 90%+ (Arabic)
- 80% chunk relevancy
